# Setup Project

1. Создать все необходимые директории проекта
2. Сгенерировать базовые файлы конфигурации (package.json, tsconfig.json, etc.)
3. Скопировать структуру компонентов из плана
4. Подготовить базовую структуру кода для frontend и backend
5. Установить необходимые зависимости
