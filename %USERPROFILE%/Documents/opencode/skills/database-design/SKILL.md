# Database Design

1. Изучи требования к структуре данных проекта
2. Создай схему базы данных, соответствующую требованиям
3. Убедись, что используется правильный тип данных и ограничения
4. Создай миграции для создания таблиц
5. Обеспечь добавление необходимых индексов для оптимизации
6. Подготовь seed данные для тестирования
7. Проверь, что все связи между таблицами корректны
