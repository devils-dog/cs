# Testing

1. Изучи требования к тестированию из документации проекта
2. Создай тесты для API endpoint'ов
3. Убедись, что тестируются все случаи использования (positive, negative)
4. Создай тесты для frontend компонентов
5. Проверь, что используются правильные методы тестирования
6. Убедись, что тесты корректно работают в среде разработки
7. Подготовь минимальные тесты для проверки основных функций
