# Security

1. Изучи требования к безопасности из документации проекта
2. Убедись, что все API endpoint'ы имеют правильную валидацию входных данных
3. Проверь, что используются безопасные практики работы с базой данных
4. Обеспечь защиту от SQL injection и других уязвимостей
5. Убедись, что секреты хранятся правильно (не в коде)
6. Проверь, что только необходимые права используются для доступа к ресурсам
7. Подготовь рекомендации по защите данных в production
