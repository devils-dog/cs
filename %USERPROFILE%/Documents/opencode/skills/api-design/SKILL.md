# API Design

1. Изучи требования к API из документации проекта
2. Создай структуру API endpoint'ов, соответствующую архитектуре проекта
3. Убедись, что все endpoint'ы корректно обрабатывают ошибки
4. Проверь, что все входные данные валидируются
5. Обеспечь согласованность формата ошибок
6. Подготовь примеры использования API для тестирования
7. Реализуй минимальную функциональность, соответствующую требованиям проекта
