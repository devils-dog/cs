# Telegram Integration

1. Изучи требования к интеграции с Telegram из документации проекта
2. Создай модуль для работы с Telegram WebApp SDK
3. Убедись, что приложение корректно работает как в Telegram, так и в браузере
4. Проверь, что используется правильная обработка тем и размеров экрана
5. Обеспечь корректную работу с кнопками и навигацией
6. Убедись, что все данные передаются правильно через Telegram
7. Подготовь тесты для проверки интеграции
