# Frontend Development

1. Изучи требования к UI из документации проекта
2. Создай структуру компонентов, соответствующую архитектуре
3. Убедись, что все компоненты корректно работают с API
4. Проверь, что используется правильная типизация TypeScript
5. Обеспечь responsive дизайн для мобильных устройств
6. Подготовь тесты для проверки компонентов
7. Убедись, что все компоненты корректно работают внутри Telegram WebApp
