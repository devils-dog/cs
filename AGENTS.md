# Общие правила

- Не придумывай отсутствующие факты.
- Перед изменением кода сначала изучи существующую реализацию.
- Если задача неоднозначна — задай уточняющие вопросы.
- Не выполняй commit, push и merge без явного разрешения.
- После изменений перечисли затронутые файлы и возможные риски.

# Рекомендации по безопасности

- Все токены и секреты должны храниться в отдельных файлах и использоваться через переменные окружения.
- Не храните токены в workspace.
- Используйте минимально необходимые права для доступа к ресурсам.
- При работе с Git используйте только разрешенные команды:
  - git status - разрешено
  - git diff * - разрешено
  - git commit * - запрещено
  - git push * - запрещено

# Рекомендации по коду

- Всегда подтверждайте изменения перед применением.
- При работе с кодом изучайте контекст проекта.
- Создавайте skills для повторяющихся задач.
- Для безопасности используйте запрет на выполнение shell-команд, если они не требуются.
